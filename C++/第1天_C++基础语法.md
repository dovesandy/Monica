## 1. C++程序基本结构

### 最简单的C++程序

``` cpp
#include <iostream>  // 包含输入输出流头文件

int main() {         // 主函数，程序入口点
    // 程序代码写在这里
    return 0;        // 程序正常结束
}
```

### 代码结构解析

* `#include <iostream>`：预处理指令，包含标准输入输出库

* `int main()`：主函数，每个C++程序都必须有且只有一个main函数

* `{}`：代码块，包含函数的执行语句

* `return 0;`：返回语句，表示程序正常退出

## 3. 变量和数据类型


## 4. 输入输出操作

### 输出数据（cout）

``` cpp

#include <iostream>
using namespace std;

int main() {
    // 输出字符串
    cout << "Hello, C++!" << endl;
    
    // 输出变量
    int number = 42;
    cout << "The number is: " << number << endl;
    
    // 连续输出
    cout << "Line 1" << " " << "Line 2" << endl;
    
    return 0;
}

```

### cout、endl、<<

* std::cout << '\n'; 只写入换行字符，不刷新缓冲（除非流处于行缓冲模式并且是交互终端）。
* std::cout << std::endl; 写入换行字符并且刷新缓冲。
* 对于性能考虑：优先使用 '\n'，只有在你需要马上看到输出（例如提示用户输入、实时日志）时才用 std::endl 或显式 std::flush()。

### 输入数据（cin）

``` cpp

#include <iostream>
using namespace std;

int main() {
    int age;
    string name;
    
    // 输入字符串
    cout << "请输入你的名字: ";
    cin >> name;
    
    // 输入数字
    cout << "请输入你的年龄: ";
    cin >> age;
    
    // 输出结果
    cout << "你好，" << name << "！你今年" << age << "岁。" << endl;
    
    return 0;
}
```

### 基本概念

* std::cin 是 C++ 标准库中预定义的输入流对象（类型为std::istream），默认连接到程序的标准输入（stdin，通常是键盘或管道）。
* 常用的输入运算符是提取运算符 >>（右移符号被重载为“从流中提取”）。例如：int x; std::cin >> x; 会从输入读取一个整数并赋给 x。

### >> 的行为（格式化输入）

>> 会跳过前导空白（空格、制表符、换行），然后读取直到下一个空白为止（对字符串而言），或读取并解析出目标类型（对整数、浮点数等）。
因此 std::cin >> str; 读取的是一个“单词”（不包含空格）。要读取整行（包含空格）要用 std::getline。
>> 在遇到无法解析的输入（比如向 int 读入非数字）时，会让 cin 进入失败状态（cin.fail() 返回 true），并停止进一步读取，直到你清除错误状态并丢弃不合法的数据。

### 常用方法

* cin.fail()：判断是否发生格式化输入错误。
* cin.eof()：判断是否到达文件/流末尾。
* cin.clear()：清除错误状态，以便继续使用流。
* cin.ignore(n, ch)：跳过最多 n 个字符或直到遇到分隔符 ch（常用于丢弃残留换行符）。

### 常见陷阱（汇总）

* 用 >> 读取字符串时不能包含空格；需要整行请用 getline。
* getline 紧接在 >> 之后会读取到残留的换行，因此要用 ignore 清除换行。
* 输入格式不匹配会使 cin 进入 fail 状态，需要 clear() + ignore() 恢复。
* 在性能敏感场景中避免频繁 flush（不要在循环中用 std::endl）。
* 多线程并发写 cin/cout 时要注意同步（通常使用互斥锁）。

## 6. 完整的实践程序

### 程序1：个人信息收集

``` cpp

#include <iostream>
#include <string>  // 包含字符串库
using namespace std;

int main() {
    // 变量声明
    string name;
    int age;
    double height;
    char initial;
    
    // 获取用户输入
    cout << "请输入你的姓氏首字母: ";
    cin >> initial;
    
    cout << "请输入你的全名: ";
    cin.ignore();  // 清除输入缓冲区
    getline(cin, name);  // 读取整行（包含空格）
    
    cout << "请输入你的年龄: ";
    cin >> age;
    
    cout << "请输入你的身高(米): ";
    cin >> height;
    
    // 显示信息
    cout << "n=== 个人信息汇总 ===" << endl;
    cout << "姓名首字母: " << initial << endl;
    cout << "全名: " << name << endl;
    cout << "年龄: " << age << "岁" << endl;
    cout << "身高: " << height << "米" << endl;
    
    return 0;
}
```

### 程序2：简单计算器

``` cpp

#include <iostream>
using namespace std;

int main() {
    double num1, num2;
    
    cout << "=== 简单计算器 ===" << endl;
    cout << "请输入第一个数字: ";
    cin >> num1;
    
    cout << "请输入第二个数字: ";
    cin >> num2;
    
    // 执行计算
    cout << "n计算结果:" << endl;
    cout << num1 << " + " << num2 << " = " << num1 + num2 << endl;
    cout << num1 << " - " << num2 << " = " << num1 - num2 << endl;
    cout << num1 << " * " << num2 << " = " << num1 * num2 << endl;
    
    // 检查除数是否为0
    if (num2 != 0) {
        cout << num1 << " / " << num2 << " = " << num1 / num2 << endl;
    } else {
        cout << "错误：除数不能为0！" << endl;
    }
    
    return 0;
}
```

## 9. 常见错误和调试技巧

### 常见语法错误

1. __缺少分号__：每条语句必须以分号结束

2. __拼写错误__：cout 不是 count，endl 不是 end1

3. __头文件缺失__：使用cin/cout需要包含<iostream>

4. __使用未声明的变量__：变量必须先声明后使用

### 调试技巧

* 使用 `cout` 输出中间结果

* 编译时注意错误信息
