# 英雄联盟网络控制器使用指南

## 📦 文件准备

### 1. 下载所需文件

您需要以下文件（来自之前的代码）：

* `LOLNetworkController.ps1` - 主控制脚本

* `LOLNetworkController.bat` - 用户界面脚本

* `NetworkConfig.json` - 配置文件（可选）

### 2. 创建文件步骤

1. 新建一个文件夹，例如：`C:\LOLController`

2. 在此文件夹中创建三个文件：

   * 新建文本文档，重命名为 `LOLNetworkController.ps1`

   * 新建文本文档，重命名为 `LOLNetworkController.bat`

   * 新建文本文档，重命名为 `NetworkConfig.json`（可选）

3. 将对应的代码复制到每个文件中

4. 确保文件扩展名正确：

   * `.ps1` 是 PowerShell 脚本

   * `.bat` 是批处理文件

   * `.json` 是配置文件

## 🚀 首次使用步骤

### 第一步：以管理员身份运行

1. 找到 `LOLNetworkController.bat` 文件

2. **右键点击**该文件

3. 选择 **"以管理员身份运行"**

> ⚠️ **重要**：必须使用管理员权限，否则无法修改网络设置

### 第二步：初始设置

程序启动后会出现菜单界面：

```
英雄联盟网络劣化控制器 V3.0
模拟网络卡顿效果（非断网）
========================================

请选择操作：
[1] 启动/重启控制器
[2] 停止控制器
[3] 查看状态和日志
[4] 测试网络劣化效果（10秒）
[5] 立即停止所有网络控制
[6] 设置开机启动
[7] 取消开机启动
[8] 查看当前网络连接
[9] 退出
```

### 第三步：设置开机启动（推荐）

1. 输入 `6` 然后按回车

2. 程序会自动设置开机启动

3. 看到"开机自启动设置成功"提示

### 第四步：测试效果

1. 输入 `4` 然后按回车

2. 输入 `Y` 确认测试

3. 程序会模拟10秒的网络卡顿效果

4. 观察英雄联盟游戏是否出现延迟/卡顿

### 第五步：启动控制器

1. 输入 `1` 然后按回车

2. 控制器会在后台启动

3. 可以关闭窗口，程序继续在后台运行

## 📊 功能详解

### 1. 自动监控功能

* **监控目标**：英雄联盟客户端 (`LeagueClient.exe`)

* **触发条件**：连续运行超过30分钟

* **执行操作**：模拟网络卡顿1分钟

* **循环机制**：恢复3分钟后，随机在10分钟内再次卡顿1分钟

### 2. 网络卡顿效果

程序会模拟以下网络问题：

* **延迟增加**：200-800ms 的网络延迟

* **数据包丢失**：10-30% 的数据包丢失率

* **网络抖动**：不稳定的延迟变化

* **带宽限制**：可选限制游戏带宽

### 3. 控制命令说明

| 选项    | 功能       | 使用场景         |
| ----- | -------- | ------------ |
| **1** | 启动/重启控制器 | 首次使用或需要重启时   |
| **2** | 停止控制器    | 需要完全停止程序时    |
| **3** | 查看状态和日志  | 检查程序运行情况     |
| **4** | 测试网络效果   | 测试网络卡顿是否有效   |
| **5** | 紧急停止控制   | 游戏出现问题需要立即恢复 |
| **6** | 设置开机启动   | 让程序开机自动运行    |
| **7** | 取消开机启动   | 不再需要开机启动时    |
| **8** | 查看网络连接   | 检查英雄联盟的网络状态  |
| **9** | 退出程序     | 退出控制界面       |

## 🔍 如何验证效果

### 方法1：在游戏中验证

1. 启动英雄联盟并登录

2. 进行一局游戏

3. 连续游戏30分钟后，观察是否出现：

   * 技能释放延迟

   * 角色移动卡顿

   * 画面不流畅

   * 高ping值显示

### 方法2：使用网络监控

1. 在游戏中按 `Ctrl+F` 显示帧数和延迟

2. 正常情况下：ping值 20-50ms

3. 网络劣化时：ping值 200-800ms

### 方法3：查看日志文件

日志文件位置：`C:\Users\[您的用户名]\AppData\Local\Temp\LOL_Network_Degrade.log`

查看日志内容：


## ⚙️ 自定义配置

### 修改运行参数

编辑 `LOLNetworkController.ps1` 文件开头部分：

powershell

复制下载

```
# 修改这些参数：
$LimitMinutes = 30        # 触发时间（分钟）
$NetworkDegradeMinutes = 1  # 卡顿时间（分钟）
$RecoveryMinutes = 3        # 恢复时间（分钟）

# 网络效果配置：
$NetworkConfig = @{
    LatencyMS = 300          # 延迟毫秒数
    JitterMS = 100           # 抖动毫秒数
    PacketLossPercent = 15   # 丢包百分比
    ThrottleKbps = 100       # 限速KB/s
}
```

## 🔧 故障排除

### 常见问题及解决方法

| 问题           | 可能原因     | 解决方法                                      |
| ------------ | -------- | ----------------------------------------- |
| **无法以管理员运行** | 用户账户控制限制 | 1. 右键选择"以管理员身份运行" 2. 关闭UAC控制              |
| **游戏没有卡顿效果** | 网络设置未生效  | 1. 运行"测试网络效果"选项4 2. 检查防火墙设置               |
| **程序自动停止**   | 被安全软件阻止  | 1. 添加程序到杀毒软件白名单 2. 关闭Windows Defender实时保护 |
| **开机不自动启动**  | 任务计划设置问题 | 1. 重新运行选项6 2. 手动检查任务计划程序                  |
| **游戏崩溃或断开**  | 网络干扰过强   | 1. 降低`NetworkConfig`中的数值 2. 使用选项5紧急恢复     |

### 手动检查程序状态

1. 打开任务管理器 (`Ctrl+Shift+Esc`)

2. 转到"详细信息"选项卡

3. 查找名为 `powershell.exe` 的进程

4. 查看"命令行"列是否包含 `LOL网络控制器`

### 重置所有设置

如果出现问题，可以：

1. 运行选项5"立即停止所有网络控制"

2. 运行选项2"停止控制器"

3. 重启电脑

4. 重新运行程序

## ⚠️ 重要注意事项

### 安全警告

1. **违反用户协议**：使用第三方程序控制游戏可能违反《英雄联盟》用户协议

2. **账号风险**：可能导致账号被封禁

3. **系统稳定性**：修改网络设置可能影响其他程序

1. **仅用于学习和测试**：不建议在正式账号上使用

3. **适度使用**：不要设置过强的干扰效果

4. **备份重要数据**：使用前备份游戏设置和个人文件

## 🆘 紧急恢复

如果出现问题，按以下步骤操作：

### 快速恢复网络

1. 运行 `LOLNetworkController.bat`

2. 选择选项 **5**（立即停止所有网络控制）

3. 等待程序执行完成

### 完全卸载程序

1. 运行 `LOLNetworkController.bat`

2. 选择选项 **2**（停止控制器）

3. 选择选项 **7**（取消开机启动）

4. 删除程序文件夹

### 手动恢复网络设置

如果程序无法正常运行，可以手动恢复：

1. 以管理员身份打开命令提示符

2. 输入以下命令：

   cmd

   复制下载

   ```
   netsh int tcp set global autotuninglevel=normal
   netsh int tcp set global ecncapability=enabled
   netsh int tcp set global nagle=disabled
   ipconfig /flushdns
   ```
