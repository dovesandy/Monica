## 科目三《信息技术学科知识与教学能力》案例分析题专项整理

根据教师资格证考试题型分布，案例分析题共**2小题，每小题20分，总计40分**，是科目三的**高分关键**。案例分析题主要考查教学实施和教学评价能力[\-5](http://www.offcn.com/jiaoshi/2016/1014/131972.html)。

## 一、案例分析题答题技巧

### 【答题结构】理论+解释+案例[\-5](http://www.offcn.com/jiaoshi/2016/1014/131972.html)

| 步骤  | 内容 | 说明                     |
| --- | -- | ---------------------- |
| 第一步 | 理论 | 找出核心得分点，明确考查的教学原则/评价方法 |
| 第二步 | 解释 | 简要解释该理论的内涵             |
| 第三步 | 案例 | 结合材料中的具体表现进行分析         |

### 【高频考查维度】

| 考查方向 | 常见考点                    |
| ---- | ----------------------- |
| 教学评价 | 评价标准多维化、评价主体多元化、评价内容全面化 |
| 教学方法 | 任务驱动法、小组合作法、自主探究法、讲授法   |
| 教学原则 | 启发性原则、直观性原则、理论联系实际原则    |
| 课堂管理 | 偶发事件处理、学生主体地位、因材施教      |

## 二、课堂偶发事件处理类

### 【典型例题1】“傻瓜原理”事件

**题目**：阅读下列材料，回答问题。[\-1](https://www.233.com/teacher/tiku/mnkc/zhongxue/xueke/monit/201608/29090455548-2.html)

算法与程序设计的复习课上，胡老师问学生计算机解决问题的步骤，有位学得不太好的学生说：“不就是傻瓜原理吗，你说他向东，他肯定不会向西”。所有同学哄堂大笑。胡老师当时很生气，学生的答案并非自己想要的，而且胡老师觉得这个学生就是想捣乱。

**问题**：  
(1)案例中的偶发事件的起因是什么？  
(2)你要是胡老师，你会如何处理这则偶发事件？谈谈你的想法。

* * *

**【参考答案】**

**(1)事件起因**（6分）

- **学生层面**：该学生对计算机解决问题步骤的理解不够深入，用通俗但不准确的“傻瓜原理”表达自己的理解，并非故意捣乱

- **教师层面**：胡老师对学生的回答期待过高，且对学生动机的判断存在偏差，将学生的真实表达误解为捣乱行为

- **课堂氛围层面**：全班哄笑反映了学生对该回答的共鸣，说明学生对抽象概念的理解存在困难

**(2)处理方式**（14分）

**第一步：冷静应对，保护学生自尊**  
我会先微笑示意大家安静，然后肯定该学生的回答：“你这个说法很有意思，‘傻瓜原理’这个比喻很形象——计算机确实需要按照我们给它的指令一步一步执行。”这样做既保护了学生发言的积极性，又为后续引导做了铺垫。

**第二步：因势利导，回归教学内容**  
接着引导：“但是，计算机到底是怎么‘傻瓜式’工作的呢？它需要哪些步骤？让我们一起来梳理一下。”将课堂焦点从哄笑状态拉回到教学内容上。

**第三步：鼓励发言，转化生成资源**  
邀请那位学生继续分享他的理解，在他的回答基础上补充完善计算机解决问题的三个步骤：分析问题→设计算法→编写程序→调试运行。肯定他的直观感受与专业概念的关联性。

**第四步：反思教学，调整策略**  
课后反思：学生对抽象概念的理解需要更直观的教学方式，下次可以多举生活实例，帮助学生建立认知桥梁。

**【处理原则总结】**  
①尊重学生，不轻易否定  
②因势利导，化“意外”为资源  
③关注学困生，调整教学策略[\-1](https://www.233.com/teacher/tiku/mnkc/zhongxue/xueke/monit/201608/29090455548-2.html)

## 三、教学评价类案例分析

### 【典型例题2】“手机贴纸图案”作品评价表

**题目**：夏老师教授的“标志的设计与制作”这节课主要内容是利用Word中的自选图形绘制图形并美化修饰。任务完成后，夏老师给出了“手机贴纸图案”作品评价表，让学生进行自评。小阳和小亮都给自己打了满分。结合小阳和小亮的自评结果，你认为此评价表存在什么问题？请你对作品评价表提出修改建议。[\-5](http://www.offcn.com/jiaoshi/2016/1014/131972.html)

* * *

**【参考答案】**

**(1)评价表存在的问题**（10分）

**①没有做到评价标准多维化**（4分）  
新课程理念下的评价标准应以绝对标准为主，绝对标准、相对标准和个体标准相结合的多维标准[\-5](http://www.offcn.com/jiaoshi/2016/1014/131972.html)。题目中的评价标准是单一的绝对标准，学生都给自己满分，说明标准缺乏区分度，无法真实反映学生水平差异。

**②没有做到评价主体多元化**（3分）  
信息技术评价主体应多元化，可以从多个方面、多个角度出发对学生进行全面、客观、科学的评价，还要能够调动学生、教师积极参与评价[\-5](http://www.offcn.com/jiaoshi/2016/1014/131972.html)。题目中只有学生自评环节，缺少学生互评和教师评价，评价结果主观性过强。

**③没有做到评价内容全面化**（3分）  
教学评价不仅要重视知识与技能，还要注重学生在过程与方法、情感态度与价值观等方面的变化[\-5](http://www.offcn.com/jiaoshi/2016/1014/131972.html)。题目中过多强调知识和技能掌握的评价，忽略了创新能力、审美情趣、合作精神等方面的评价。

**(2)修改建议**（10分）

**①多维度评价作品**（4分）  
不完全按照分数进行评价，可以增加班级排名等相对评价，还可以评选出“最佳创意奖”“最美观奖”“最实用奖”等多维度的评价形式[\-5](http://www.offcn.com/jiaoshi/2016/1014/131972.html)。

**②多元化评价主体**（3分）  
在表格后面增加小组互评、教师评价等形式，形成“自评+互评+师评”的多元评价体系，使评价结果更加客观全面。

**③全面化评价内容**（3分）  
在评价项目中增加过程评价中的创新实践方面的评价，增加情感态度价值观方面的美观性评价，如“作品创意性”“团队合作表现”“解决问题能力”等指标。

## 四、教学过程分析类

### 【典型例题3】“设计一个旅行计划”分组合作问题

**题目**：《综合活动，设计一个旅行计划》是高中必修教材第二章第四节的内容。教师首先利用一段视频介绍自己完成的旅行计划，然后让学生通过小组合作完成一个小组旅行计划。本课老师将每排10个学生分成一组，进行“分组合作学习”，表面上热热闹闹，结果却不尽人意。分析造成这一现象的原因。[\-1](https://www.233.com/teacher/tiku/mnkc/zhongxue/xueke/monit/201608/29090455548-2.html)

* * *

**【参考答案】**

**(1)分组合作效果不佳的原因**（8分）

**①分组不合理**（3分）  
每排10个学生一组，小组规模过大。有效合作学习的小组一般以4-6人为宜，人数过多会导致部分学生“搭便车”，参与度不均衡。

**②缺乏明确分工**（3分）  
教师没有给小组内成员分配具体角色和任务，导致合作流于形式，表面上热热闹闹，实际上缺乏深度参与和实质进展。

**③任务设计不精细**（2分）  
“设计旅行计划”任务较开放，但没有分解成可操作的具体步骤，学生不知从何入手。

**(2)有效分组合作策略**（12分）

**①合理分组**（3分）  
每组4-6人，遵循“组内异质、组间同质”原则，考虑学生能力、性格差异，促进互补学习。

**②明确分工**（4分）  
为每位组员分配角色，如组长（协调进度）、记录员（记录讨论内容）、资料员（查找资料）、汇报员（展示成果）等，让每个人都有具体任务。

**③设计可操作的任务**（3分）  
将大任务分解为小步骤：确定旅行目的地→查找交通方式→规划行程安排→预算费用→制作展示PPT。每个步骤有明确产出。

**④建立评价机制**（2分）  
采用“个人贡献分+小组作品分”的评价方式，既激励个人参与，又促进团队合作。

## 五、教学意图与教学方法类

### 【典型例题4】分析教师的教学意图和方法

**题目**：阅读下列材料，分析教师采用了哪些教学方法，并说明其教学意图。[\-8](https://blog.csdn.net/menggu_vicco/article/details/123282146)

在“用Python实现简单计算器”一课中，王老师首先演示了一个完整的计算器程序，让学生感受程序的魅力。然后，他要求学生分组讨论计算器需要实现哪些功能，并画出程序流程图。在学生讨论过程中，王老师巡回指导，对遇到困难的小组给予提示。

* * *

**【参考答案】**

**(1)采用的教学方法**（8分）

| 教学方法    | 材料体现                | 判断依据          |
| ------- | ------------------- | ------------- |
| 演示法     | 王老师首先演示了一个完整的计算器程序  | 教师操作演示，学生观察感知 |
| 小组合作法-8 | 要求学生分组讨论计算器需要实现哪些功能 | 学生分组讨论，合作完成任务 |
| 任务驱动法-8 | 布置“画出程序流程图”的任务      | 以具体任务驱动学习     |
| 巡回指导法   | 在学生讨论过程中巡回指导，给予提示   | 教师关注差异，个别指导   |

**(2)教学意图分析**（12分）

**①演示完整程序的意图**（3分）  
通过展示完整的、可运行的程序成果，让学生直观感受编程的魅力和应用价值，激发学习兴趣和动机。这体现了“从感性到理性”的教学规律。

**②分组讨论的意图**（3分）  
突出学生主体地位，培养互帮互助的学习氛围[\-8](https://blog.csdn.net/menggu_vicco/article/details/123282146)。让学生在交流碰撞中拓展思路，锻炼合作交流能力，培养分析问题的能力。

**③任务驱动设计的意图**（3分）  
以真实任务为载体，让学生在“做中学”，培养解决实际问题的能力。流程图绘制有助于培养学生的计算思维和算法设计能力。

**④巡回指导的意图**（3分）  
关注个体差异，对学困生及时给予帮助，对学优生提供拓展指导，体现因材施教原则，确保全体学生都能获得发展。

## 六、教学评价设计类

### 【典型例题5】评价表设计问题分析

**题目**：在作品评价环节，教师设计了如下评价表，要求学生自评。结果大多数学生都给自己打了高分，无法区分作品质量。分析该评价表存在的问题，并提出修改建议。

| 评价项目  | 分值  | 自评得分 |
| ----- | --- | ---- |
| 作品完整性 | 30分 |      |
| 技术运用  | 30分 |      |
| 美观性   | 20分 |      |
| 创意性   | 20分 |      |

* * *

**【参考答案】**

**(1)评价表存在的问题**（8分）

**①评价指标过于笼统**（3分）  
“作品完整性”“技术运用”等指标缺乏具体描述，学生不清楚什么样的作品算“完整”、什么程度算“技术运用好”，导致评分主观随意。

**②缺乏评分标准描述**（2分）  
没有给出每个分值对应的表现标准，学生无法准确判断自己应得多少分。

**③评价主体单一**（2分）  
只有学生自评，缺少互评和师评，评价结果主观性过强。

**④缺乏反馈空间**（1分）  
没有设置评语或改进建议栏，评价失去了促进改进的功能。

**(2)修改建议**（12分）[\-5](http://www.offcn.com/jiaoshi/2016/1014/131972.html)

**①细化评价指标，增加等级描述**

| 评价项目        | 评价标准描述    | 优秀(8-10)   | 良好(5-7)      | 合格(1-4)       | 自评 | 互评 | 师评 |
| ----------- | --------- | ---------- | ------------ | ------------- | -- | -- | -- |
| 作品完整性 (10分) | 功能完整，运行无误 | 功能完整，无bug  | 主要功能实现，有小bug | 部分功能实现，有明显bug |    |    |    |
| 技术运用 (10分)  | 恰当运用所学技术  | 技术运用恰当，有创新 | 技术运用基本合理     | 技术运用不当或单一     |    |    |    |
| 美观性 (10分)   | 界面布局合理，美观 | 布局美观，色彩协调  | 布局基本合理       | 布局混乱          |    |    |    |
| 创意性 (10分)   | 有独特创意     | 创意新颖独特     | 有一定创意        | 缺乏创意          |    |    |    |

**②增加评价主体**（3分）  
设置“自评+互评+师评”多元评价，互评可以促进相互学习，师评保证评价专业性。

**③增加反馈空间**（2分）  
在表格下方设置“作品亮点”“改进建议”等开放性反馈栏，发挥评价的诊断和改进功能。

**④设置权重和总分**（2分）  
明确各项权重，计算总分，便于横向比较和等级评定。

## 七、综合案例深度分析

### 【典型例题6】“Python索引与切片”教学案例分析

**题目**：阅读王焱老师《解析运动会号码表》的教学片段，从核心素养培养角度分析该教学设计的优点。[\-9](https://jfy.pudong-edu.sh.cn/web/PDJFY/4560004-4560000017207.htm?Page=77)

教学片段：  
王老师以学校即将召开的运动会为背景，展示运动员号码表，引导学生分析号码中包含的年级、班级、性别、学号等信息，自然引入课题。通过讲授Python中索引和切片的概念，王老师设计了一个小游戏——按正确顺序输出打乱顺序的诗句，让学生在游戏中巩固理解。实践活动环节，学生需利用索引和切片操作，从CSV文件中读取号码字段数据，完成输出每位运动员的班级、学号、性别，以及统计男子和女子运动员人数等分层任务。

* * *

**【参考答案】**

**从核心素养培养角度的优点分析**（20分）

| 核心素养维度        | 教学设计体现                                         | 培养效果                              |
| ------------- | ---------------------------------------------- | --------------------------------- |
| 信息意识 (5分)     | 以学校运动会号码表为真实情境，引导学生分析号码中包含的信息                  | 让学生认识到数据处理在生活中的广泛应用，形成主动获取信息的意识-9 |
| 计算思维 (5分)     | 通过索引和切片概念讲解，引导学生理解如何从序列中提取特定数据；游戏化设计帮助学生理解抽象概念 | 培养问题分解能力和逻辑思维能力，学会用计算思维解决问题       |
| 数字化学习与创新 (5分) | 分层任务设计：从CSV文件读取数据→输出运动员信息→统计男女运动员人数            | 通过完整的数据处理流程，提升实践能力和创新应用能力-9       |
| 信息社会责任 (5分)   | 强调数据处理的规范性，引导学生正确使用数据                          | 培养严谨的科学态度和数据隐私意识                  |

**总体评价**（补充加分点）：

- **情境真实**：运动会号码表贴近学生生活，增强学习的真实性和代入感[\-9](https://jfy.pudong-edu.sh.cn/web/PDJFY/4560004-4560000017207.htm?Page=77)

- **任务分层**：基础实践→进阶应用→拓展延伸，照顾学生差异，让每个学生都有获得感

- **游戏化教学**：诗句排序游戏降低了抽象概念的认知难度，提高学习兴趣

## 九、考场答题提醒

1. **审题要清**：先看问题问什么，再带着问题读材料

2. **理论先行**：每个得分点先亮出理论术语

3. **结合材料**：一定要有“材料中……”的具体分析

4. **分条作答**：用序号标清层次，卷面整洁
