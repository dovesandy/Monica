## 科目一：《综合素质》——材料分析题满分模板

科目一材料分析题第一道考**职业理念（三观）**，第二道考**教师职业道德**。今天必须把这两道大题的答题模板背熟！

### 🔥 核心考点1：职业理念——“三观”答题模板

材料分析题第一问通常是：“请从教育观/学生观/教师观的角度，评析某老师的教育行为。”

**【答题步骤】**

1. **总体评价**：该老师的教育行为是正确/错误的，符合/违背了……的要求。

2. **理论+材料**：分条列举理论，每条后面紧跟材料中的具体表现。

3. **总结**：综上所述，作为教师应当……

#### 1\. 教育观（素质教育的内涵）

**【理论要点】（记忆口诀：**全体面创个**）**

- **全体**：面向全体学生（材料表现：不放弃差生、平等对待）

- **全面**：促进学生全面发展（材料表现：不只关注成绩，也培养品德、智、体、美、劳）

- **创新**：重点培养学生创新精神和实践能力（材料表现：鼓励学生动手、提问、探究）

- **个性**：促进学生个性发展（材料表现：因材施教、尊重特长）

#### 2\. 学生观（“以人为本”的学生观）

**【理论要点】（记忆口诀：**两独一发**）**

- **发展的人**：学生具有巨大的发展潜能，是处于发展过程中的人（材料表现：相信学生能进步、容错）

- **独特的人**：学生是完整的人，每个学生都有独特性（材料表现：因材施教、看到学生的闪光点）

- **独立意义的人**：学生是学习的主体，具有主观能动性（材料表现：尊重学生想法、引导学生自主探究）

#### 3\. 教师观（新课程背景下的教师角色）

**【理论要点】（记忆口诀：**促进研究建社区**）**

- **学生学习的促进者**：从知识传授者转变为引导者（材料表现：启发式教学）

- **教育教学的研究者**：善于反思、研究问题（材料表现：写教学反思、改进方法）

- **课程的建设者和开发者**：创造性地使用教材（材料表现：开发校本课程、整合资源）

- **社区型开放的教师**：注重与社区、家长合作（材料表现：家访、利用社区资源）

### 🔥 核心考点2：教师职业道德——“三爱两人一终身”

材料分析题第二问通常是：“请从教师职业道德的角度，评析某老师的教育行为。”

**【答题模板】**

| 口诀  | 规范名称 | 核心内涵      | 材料关键词           |
| --- | ---- | --------- | --------------- |
| 三爱  | 爱国守法 | 热爱祖国，依法执教 | 不侵犯学生权利、不体罚     |
|     | 爱岗敬业 | 认真备课，甘为人梯 | 勤恳负责、无私奉献       |
|     | 关爱学生 | 公平公正，严慈相济 | 关心全体、不歧视、保护安全   |
| 两人  | 教书育人 | 因材施教，全面育人 | 循循善诱、不以分数作为唯一标准 |
|     | 为人师表 | 以身作则，廉洁从教 | 语言文明、拒绝红包、团结同事  |
| 一终身 | 终身学习 | 拓展视野，更新知识 | 参加培训、读书学习、钻研业务  |

> **【答题示范】**  
> 该老师的做法体现了/违背了“关爱学生”的职业道德。关爱学生要求教师关心爱护全体学生，尊重学生人格，平等公正对待学生。材料中，老师……（具体行为），这符合/违背了关爱学生的要求。

## 科目二：《教育知识与能力》——中学教学与德育

这是科目二简答题和材料分析题的必考点，今天必须拿下！

### 🔥 核心考点1：教学原则（简答题、材料题高频）

**【八大教学原则】（记忆口诀：**冯巩找阴凉，寻思理直发**）**

| 原则        | 含义         | 古文/关键词        |
| --------- | ---------- | ------------- |
| 巩固性       | 及时复习       | “学而时习之”       |
| 直观性       | 实物、模象、语言直观 | 不直接讲，先看实物     |
| 启发性       | 引导学生思考     | “不愤不启，不悱不发”   |
| 循序渐进      | 由浅入深       | “学不躐等”“不陵节而施” |
| 量力性       | 适合学生水平     | “跳一跳摘桃子”      |
| 因材施教      | 针对差异       | 一把钥匙开一把锁      |
| 理论联系实际    | 学以致用       | 学以致用，生活经验     |
| 思想性与科学性统一 | 知识+品德      | 既教书又育人        |

> **【答题技巧】** 材料分析题中，看到老师举例子、联系生活——**理论联系实际**；看到老师提问引导学生——**启发性原则**；看到老师用多媒体展示——**直观性原则**。

### 🔥 核心考点2：教学方法（选择题）

**【四大类教学方法】**

| 分类  | 具体方法              | 关键词           |
| --- | ----------------- | ------------- |
| 语言性 | 讲授法、谈话法、讨论法、读书指导法 | 老师讲、师生问答、小组讨论 |

## 二、科目三：《信息技术学科知识与教学能力》——网络与数据库

这是科目三选择题和简答题的重灾区，今天攻克两大模块！

### 🔥 核心考点1：网络技术基础

#### 1\. OSI（Open System Interconnect）七层模型（记忆口诀：**物链网传会表应**——谐音：物联网传会表应）

| 层数 | 名称    | 功能          | 协议/设备             |
| -- | ----- | ----------- | ----------------- |
| 7  | 应用层   | 直接为应用进程提供服务 | HTTP、FTP、SMTP、DNS |
| 6  | 表示层   | 数据格式转换、加密解密 | JPEG、ASCII        |
| 5  | 会话层   | 建立、管理、终止会话  | NetBIOS           |
| 4  | 传输层   | 端到端通信、流量控制  | TCP、UDP           |
| 3  | 网络层   | 路由选择、IP寻址   | IP、路由器            |
| 2  | 数据链路层 | 物理寻址、差错控制   | 交换机、MAC地址         |
| 1  | 物理层   | 比特流传输       | 集线器、网线            |

> **【高频考点】**
>
> - TCP/IP协议是事实标准，对应OSI的传输层+网络层
>
> - IP地址属于网络层，MAC地址属于数据链路层
>

#### 2\. IP地址与子网掩码

- **IPv4地址**：32位二进制，点分十进制（如192.168.1.1）

- **地址分类**：

  - **A类**：1-126（大型网络）

  - **B类**：128-191（中型网络）

  - **C类**：192-223（小型网络）

  - **D类**：224-239（组播）

  - **E类**：240-255（实验）

- **特殊地址**：

  - **127.0.0.1**：本地回环地址（测试本机）

  - **192.168.x.x / 10.x.x.x / 172.16-31.x.x**：私有地址（局域网用）

  - **255.255.255.255**：广播地址

#### 3\. 常见网络设备

| 设备  | 工作层级   | 功能             |
| --- | ------ | -------------- |
| 集线器 | 物理层    | 信号放大，共享带宽（冲突域） |
| 交换机 | 数据链路层  | MAC地址转发，隔离冲突域  |
| 路由器 | 网络层    | IP地址转发，连接不同网络  |
| 网关  | 传输层及以上 | 协议转换，连接异构网络    |

### 🔥 核心考点2：数据库技术基础

#### 1\. 数据库系统三级模式结构

- **外模式**（用户视图）：用户能看到的局部数据

- **概念模式**（逻辑视图）：全局逻辑结构

- **内模式**（物理视图）：存储方式

#### 2\. E-R图（实体-联系图）

- **实体**：矩形框（学生、课程）

- **属性**：椭圆形框（学号、姓名）

- **联系**：菱形框，三种类型：

  - **1:1**（一对一）：一个学生一个学号

  - **1:N**（一对多）：一个班级多个学生

  - **M:N**（多对多）：一个学生选多门课，一门课被多个学生选

#### 3\. SQL语言（结构化查询语言）

- **数据定义**：CREATE（创建）、DROP（删除）、ALTER（修改）

- **数据操纵**：INSERT（插入）、UPDATE（更新）、DELETE（删除）

- **数据查询**：SELECT（查询）——**最常考！**
