# macOS 快捷键大全

## 系统与界面

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Command + Space` | 打开 Spotlight 搜索 |
| `Control + Command + Space` | 打开字符表情与符号查看器 |
| `Command + H` | 隐藏当前窗口 |
| `Command + M` | 最小化当前窗口 |
| `Command + W` | 关闭当前窗口/标签页 |
| `Command + Q` | 退出当前应用 |
| `Command + Tab` | 在打开的应用间切换 |
| `Command + ` (反引号) | 在同一应用的不同窗口间切换 |
| `Control + ↑` | 打开调度中心 (Mission Control) |
| `Control + ↓` | 显示当前应用的所有窗口 |
| `F11` | 显示桌面 (临时移开所有窗口) |
| `Command + ,` (逗号) | 打开当前应用的偏好设置 |

## 文件与Finder

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Command + N` | 新建 Finder 窗口 |
| `Command + Shift + N` | 新建文件夹 |
| `Command + O` | 打开选中的文件/文件夹 |
| `Command + I` | 显示“显示简介”窗口 |
| `Command + Delete` | 将选中文件移至废纸篓 |
| `Command + Shift + Delete` | 清空废纸篓 (需加 `Option` 跳过确认) |
| `Space` | 快速查看 (预览文件内容) |
| `Command + D` | 复制选中文件 (创建副本) |
| `Command + E` | 推出所选磁盘或卷宗 |

## 文本编辑

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Command + A` | 全选 |
| `Command + C` | 复制 |
| `Command + X` | 剪切 |
| `Command + V` | 粘贴 |
| `Command + Z` | 撤销 |
| `Command + Shift + Z` | 重做 |
| `Command + B` | 加粗 |
| `Command + I` | 斜体 |
| `Command + U` | 下划线 |
| `Command + F` | 在文档中查找 |
| `Command + →` | 将光标移至当前行行尾 |
| `Command + ←` | 将光标移至当前行行首 |
| `Option + →` | 将光标移至下一个单词的末尾 |
| `Option + ←` | 将光标移至上一个单词的开头 |

## 截图与录屏

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Shift + Command + 3` | 全屏截图 |
| `Shift + Command + 4` | 区域截图 (随后可按 `Space` 切换为窗口截图) |
| `Shift + Command + 5` | 打开截图/录屏工具栏 (可录制屏幕) |
| `Shift + Command + 6` | 触控栏截图 (带触控栏的机型) |

## 浏览器 (Safari/Chrome)

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Command + T` | 打开新标签页 |
| `Command + W` | 关闭当前标签页 |
| `Command + R` | 刷新页面 |
| `Command + L` | 光标跳转至地址栏 |
| `Command + +` | 放大页面 |
| `Command + -` | 缩小页面 |
| `Command + [` | 后退 |
| `Command + ]` | 前进 |

## 特殊功能

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Command + Option + Esc` | 强制退出应用 (任务管理器) |
| `Power Button` (长按1.5秒) | 显示关机/重启/睡眠对话框 |
| `Command + Control + Power Button` | 强制 Mac 重启 |
| `Touch ID` (连按5次) | 弹出紧急 SOS 对话框 (适用于带触控栏的机型) |
| `Fn + F` | 切换功能键模式 (使用 F1-F12 原生功能) |

> **提示**：
> - 许多快捷键可在**系统设置 > 键盘 > 键盘快捷键**中自定义。
> - `Option` 键常作为修饰键与其他键组合，触发隐藏或高级功能。
> - 不同应用可能有其专属的快捷键，请在应用的菜单栏中查看。
