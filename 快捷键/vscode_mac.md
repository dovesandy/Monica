# Visual Studio Code 快捷键大全 (macOS)

## 基础编辑 (Basic Editing)

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Cmd + X` | 剪切当前行（未选中内容时） |
| `Cmd + C` | 复制当前行（未选中内容时） |
| `Cmd + V` | 粘贴 |
| `Cmd + Shift + K` | **删除整行** |
| `Cmd + Enter` | 在下方插入新行 |
| `Cmd + Shift + Enter` | 在上方插入新行 |
| `Option + ↑` | 向上移动行 |
| `Option + ↓` | 向下移动行 |
| `Cmd + Shift + \` | 跳转到匹配的括号 |
| `Cmd + ]` | 增加行缩进 |
| `Cmd + [` | 减少行缩进 |
| `Cmd + /` | 添加/移除行注释 |
| `Option + Shift + A` | 添加/移除块注释 |

## 导航 (Navigation)

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Cmd + P` | **快速打开**，跳转到文件 |
| `Cmd + Shift + O` | 跳转到文件中的符号（类、函数等） |
| `Ctrl + G` | 跳转到指定行号 |
| `F12` | 跳转到定义 |
| `Option + F12` | 预览定义（Peek） |
| `Shift + F12` | 显示引用 |
| `F8` | 跳转到下一个错误或警告 |
| `Shift + F8` | 跳转到上一个错误或警告 |
| `Ctrl + -` | 后退（到上一个光标位置） |
| `Ctrl + Shift + -` | 前进（到下一个光标位置） |
| `Cmd + B` | 显示/隐藏侧边栏 |

---

> **提示：**
> 1.  **终极快捷键**：`Cmd + Shift + P` 可以让你通过输入命令名称来执行几乎所有操作，无需记忆所有快捷键。
> 2.  **自定义**：你可以通过 `Cmd + Shift + P` 输入 `Preferences: Open Keyboard Shortcuts` 来查看和修改所有快捷键。
> 3.  许多快捷键（如 `Cmd + F`）的行为会根据当前焦点所在的区域（编辑器、终端、侧边栏）而变化。
